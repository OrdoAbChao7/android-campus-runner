# Task 2 brief — typed RunIntent, state machine, and evidence journal

Read this first; it is the complete requirements for Task 2.

Implement a deterministic safety kernel in the current repository. Add `src/android_runner/intent.py`, `src/android_runner/state.py`, and `src/android_runner/evidence.py` plus focused tests. `RunIntent` must be immutable and bind: single-use intent id, exact ADB serial, device fingerprint, current and target enterprise, route SHA-256, not-before/not-after timestamps, maximum duration, and an explicit allow-list of action IDs. Provide validation against observed device/route/time and a single-use consume operation that rejects replay or mutation. Define the states `IDLE`, `DEVICE_LOCKED`, `PREFLIGHT_OK`, `ACCOUNT_VERIFIED`, `PAGE_READY`, `PROVIDER_READY`, `START_AUTHORIZED`, `RUNNING_VERIFIED`, `ROUTE_RUNNING`, `ROUTE_COMPLETE`, `APP_RESULT_VERIFIED`, `PROVIDER_STOPPED`, `EVIDENCE_CAPTURED`, `ACCOUNT_SWITCHED`, `DONE`, and `SAFE_STOP`; illegal transitions must raise a typed error and failures must be journaled. Evidence writer appends JSONL events and writes JSON snapshots without secrets. Keep APIs small and dependency-free. Run `pytest -q`, commit focused changes, and write report to `.superpowers/sdd/2026-08-31-agent-first-runner-plan/task-2-report.md`. Do not spawn subagents or push.
